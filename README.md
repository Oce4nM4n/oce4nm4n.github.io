# Personal Website

This is my take on a personal website, which will (eventually) become a research notebook and technical blog. This is primarily built with Astro.

It is currently a work in progress

## Quick Start

```bash
git clone https://github.com/Oce4nM4n/oce4nm4n.github.io
cd personal-website
npm install
npm run dev
```

## Scripts

| Command                | Description                      |
| ---------------------- | -------------------------------- |
| `npm run dev`          | Start development server         |
| `npm run build`        | Build for production             |
| `npm run preview`      | Preview production build         |
| `npm run check`        | Run Astro type checking          |
| `npm run format`       | Format all files with Prettier   |
| `npm run format:check` | Check formatting without changes |

## Tech Stack

- **Framework:** Astro
- **Styling:** Tailwind CSS
- **Content:** Markdown + Content Collections
- **Math:** KaTeX
- **Code:** Expressive Code
- **Hosting:** GitHub Pages


### Work in Progress
- **Search:** Pagefind
- **Analytics:** Cloudflare Web Analytics
